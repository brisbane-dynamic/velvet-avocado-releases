## Velvet Avocado Studio release notes

Velvet Avocado Studio is actively developed, with dated release notes documenting new creative tools, production workflow improvements, provider integrations, performance work, and reliability fixes. [Browse the complete release history](releases/README.md).

Velvet Avocado Studio is an AI video production workspace for filmmakers, content creators, artists, agencies, and creative teams working with generative AI. It gives every project one organised home for its characters, locations, props, costumes, scenes, shots, prompts, references, takes, generation history, costs, and finished media.

AI image and video generators are good at producing individual outputs. They are not designed to manage an entire production. As a project grows, useful prompts disappear into notes, reference images become difficult to identify, downloads lose their context, and each provider introduces another interface and account to manage. Velvet Avocado Studio sits above those tools and turns that collection of files and services into a connected creative workflow.

It is designed to feel less like another AI generator and more like the place where you make the thing.

## AI video production, organised around the project

Velvet Avocado uses a project-first workflow. Instead of treating every image, video clip, audio file, or prompt as an isolated result, the app keeps each item connected to the production it belongs to.

Create reusable libraries for **Characters**, **Locations**, **Props**, and **Costumes**, then organise the production into **Scenes** and **Shots**. Store descriptions, references, tags, favourites, production numbers, and related media with the creative asset itself. When you need the same character in a later scene or the same location from a different angle, the material you used before is still available and searchable.

This structure works for quick experiments as well as larger AI-native video projects, including:

- AI films, trailers, and narrative scenes;
- commercials, product videos, and advertising campaigns;
- music videos and visualisers;
- YouTube videos and shorts;
- TikTok, Instagram, and social media content; and
- recurring series that need consistent characters, locations, and styles.

## Generate images, video, and audio from one workspace

Velvet Avocado Studio brings multi-provider AI generation into a consistent desktop workflow. Choose a model, write the prompt, attach project media, set the available model controls, select a destination, review the estimated cost, and submit the generation without losing the context around it.

The app supports cloud, subscription, and local generation routes. Its launch ecosystem includes **ComfyUI**, **Atlas Cloud**, **WaveSpeed**, **Higgsfield**, **OpenRouter**, and **Ollama**, with each integration used for the capabilities it actually provides. This lets creators choose a model based on quality, speed, cost, availability, or local hardware instead of rebuilding their production workflow around one provider.

Generation features include:

- searchable model catalogues and favourite models;
- model-specific controls generated from provider capabilities;
- image, video, and audio reference inputs;
- first-frame and last-frame assignments for supported video models;
- cost estimates before supported generation requests are submitted;
- multiple-result generation for comparing alternatives;
- a durable generation queue with running, completed, failed, and archived views; and
- automatic placement of completed outputs into the selected project folder, scene, or asset.

Changing providers does not mean abandoning the project structure. Prompts, inputs, settings, generated outputs, and available cost information remain part of the same production record.

## Prompt management with reusable project context

Velvet Avocado Studio includes a shared prompt composer and a dedicated Generate Media workspace. Both surfaces use the same live draft, including the selected model, parameters, attachments, destination, and cost estimate, so a prompt can move between a compact production dock and a full generation screen without being rebuilt.

Prompts can refer directly to project assets and attached media. Reference a character, location, prop, or costume from the project library, attach its chosen image, and keep that identity connected to the generation request. For supported video workflows, media can also be assigned explicit roles such as a first or last frame.

The built-in **Prompt Library** provides reusable templates that can be created, edited, duplicated, favourited, filtered, and inserted into the active draft. Submitted prompts and generation records remain available later, making it easier to revisit a successful approach, compare takes, or reload an earlier job without starting again from memory.

## Searchable media and production asset management

Velvet Avocado is also a local AI media manager. Import images, video, audio, documents, and references into the project, then browse them through consistent media views rather than hunting through a downloads folder.

The media library supports search and filtering by media type, folder, tag, role, and favourite status. Generated and imported files retain project-aware metadata and can be assigned to Characters, Locations, Props, Costumes, Scenes, or Sound categories. Image and video media can be reviewed in a full-screen viewer, while audio remains playable from the project browser.

Because generation history and production assets live together, a useful output can become more than a filename. It can be reviewed, tagged, reused as a future reference, assigned to the correct part of the production, and traced back to the prompt and generation job that created it.

## AI-assisted creative planning and project chat

The Studio chat workspace connects supported cloud models, local Ollama models, and compatible local coding-agent runtimes to the active project. Chat can use bounded project context, work with saved conversations, stream replies, and turn reviewed results into generation prompts.

Velvet Avocado also provides structured Studio Functions for creative work such as prompt development, project planning, and screenplay or story breakdown. Where a requested action can change the project, the app keeps the execution behind explicit review and approval instead of treating unstructured assistant prose as permission.

The result is an AI production assistant that works inside the project rather than another disconnected chat tab.

## Built-in video editing and professional handoff

The experimental **Editor** gives each project a timeline-based space for assembling image, video, and audio media into a rough cut. Create Video Edits, use familiar keyboard-shortcut profiles, choose video, cinema, or social resolution presets, and render exports back into the Velvet Avocado project.

For work that will be finished elsewhere, timeline interchange exports can be created in **OpenTimelineIO** or **FCPXML** formats. This provides a path from AI generation and project organisation into professional post-production tools without turning the original project library into another pile of duplicate files.

## Generation cost and usage reporting

When providers expose usable pricing or final billing information, Velvet Avocado keeps it with the generation job. The project **Usage** report can filter activity by period, provider, status, and archive state; compare known estimates with actual charges; group results by provider, model, media type, billing type, or status; and export reports as PDF, XLSX, or CSV.

This makes it easier to understand where a production is spending money while keeping unknown provider costs and local-compute activity distinct from known charges.

## Local-first desktop software

Velvet Avocado Studio is local-first. Project files and media live on your computer by default in a portable folder structure. Cloud services are optional connectors for generation and reasoning, not the owner of the project. Compatible local workflows can run on your own hardware, and creators remain free to mix local tools with cloud providers according to the needs of each shot.

The application is built as desktop software for macOS and Windows, with native project folders, file import, media browsing, secure credential storage, and project-aware output placement. That local foundation is intended to keep a production understandable and usable outside the app as well as inside it.
