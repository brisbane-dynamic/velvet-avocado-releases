# Velvet Avocado Studio

**A local-first desktop production workspace for creating AI-generated video, images, audio, and complete media projects across multiple AI providers and local models.**

[**Download Velvet Avocado Studio for macOS or Windows →**](https://velvetavocado.com/download)

Velvet Avocado Studio is built for filmmakers, content creators, artists, agencies, and creative teams working with generative AI.

Organise characters, locations, props, costumes, scenes, shots, prompts, references, generations, costs, and finished media inside one project. Generate images, video, audio, and speech across multiple AI providers and local models. Analyse screenplays and turn them into structured production assets. Track generation history and spending. Assemble and refine scenes in a streamlined built-in video editor, then export timelines into professional post-production software.

Velvet Avocado Studio is built around a simple idea:

**AI generators create outputs. A production needs a workflow.**

As an AI video project grows, prompts disappear into notes and chat histories, reference images become difficult to identify, generations accumulate in download folders, and every new provider introduces another interface, history, account, and workflow.

Velvet Avocado Studio gives the production a permanent home while allowing creators to choose the best model, provider, or local tool for each part of the job.

## AI video production organised around the project

Velvet Avocado Studio uses a project-first production model rather than treating every generated image, video clip, audio file, or prompt as an isolated result.

Create reusable production libraries for:

- Characters
- Locations
- Props
- Costumes
- Scenes
- Shots
- Sound
- Generated and imported media

Each asset can carry descriptions, references, tags, favourites, production numbers, metadata, and related media.

Characters and locations can be reused across scenes. Reference images remain attached to the assets they describe. Generated takes stay connected to their prompts and generation jobs. Scenes and shots provide production structure for larger projects while remaining lightweight enough for quick experiments.

Velvet Avocado Studio supports workflows including:

- AI films and narrative scenes;
- trailers and cinematic sequences;
- commercials and advertising campaigns;
- product videos;
- music videos and visualisers;
- YouTube videos and shorts;
- TikTok, Instagram, and social media video;
- recurring series with consistent characters and locations; and
- generative animation and experimental filmmaking.

## Generate media without leaving the production workflow

The Generate Media workspace provides a consistent interface across supported providers and models.

Generation features include:

- searchable model catalogues;
- favourite models;
- model-specific generation controls;
- image, video, and audio reference inputs;
- first-frame and last-frame assignments for compatible video models;

## Screenplay analysis and production breakdown

Velvet Avocado Studio can analyse a screenplay and turn it into a structured starting point for an AI video production.

Import screenplays in:

- Fountain
- Final Draft
- plain text

Velvet Avocado Studio analyses the screenplay and identifies:

- Characters
- Locations
- Costumes
- Props
- Scenes

The analysis can create project asset stubs for these elements, with descriptions and metadata derived from the screenplay.

A detected character can become a Character asset ready for visual development. A location can become a Location asset. Props and costumes can populate their corresponding production libraries, while screenplay scenes can become structured Scene assets ready for references, media, prompts, and shots.

Instead of manually reading through a screenplay and recreating its production structure one item at a time, creators can move directly from script analysis into character, location, prop, costume, and scene development.

### Building toward an end-to-end production pipeline

The screenplay breakdown system also establishes the foundation for the longer-term direction of Velvet Avocado Studio: an end-to-end workflow connecting screenplay analysis with assisted and automated character development, location development, scene development, and media generation.

The current screenplay tools create the structured production foundation. Future development will extend what Velvet Avocado Studio can build and generate from that structure while keeping creators in control of creative decisions.

## Generation queue and production history

AI video production often involves many generations running across different providers, models, and media types.

Velvet Avocado Studio maintains a durable generation queue with dedicated views for:

- running jobs;
- completed generations;
- failed generations; and
- archived generations.

Generation records preserve the prompt, selected model, provider, parameters, input media, output media, available cost information, and project destination associated with each job.

Completed generations remain available for review, comparison, reuse, or use as references in later generation jobs.

## Generation cost tracking and usage reporting

Velvet Avocado Studio tracks generation spending as part of the production workflow.

When a provider supplies pricing or billing information, that information is stored with the generation job.

The Usage workspace provides reporting across providers, models, media types, billing types, generation status, and time periods.

Usage reporting includes:

- estimated generation costs;
- actual provider charges where supplied;
- comparison of estimates and final charges;
- filtering by provider, status, archive state, and date;
- grouping by provider, model, media type, billing type, or status; and
- export to PDF, XLSX, or CSV.

Unknown provider costs and local-compute activity remain distinct from known cloud charges.

For creators and production teams working across multiple AI services, this provides one view of production spending instead of requiring costs to be reconstructed from separate provider dashboards.

## Prompt management and reusable production context

Velvet Avocado Studio includes a shared prompt composer, a dedicated Generate Media workspace, and a reusable Prompt Library.

Characters, locations, props, costumes, images, video clips, audio, and other project media can be attached directly to generation requests.

The Prompt Library supports:

- reusable prompt templates;
- editing and duplication;
- favourites;
- filtering and search;

- reuse of successful approaches across later shots.

Submitted prompts remain connected to their generation records, making it possible to return to an earlier take, inspect how it was created, compare alternatives, or create another generation from a proven setup.

Import and organise:

## A streamlined video editor built into the creative workflow

Velvet Avocado Studio includes a streamlined timeline-based video editor designed to keep creators in the creative flow while they assemble scenes, evaluate generations, and refine prompts.

The timeline is not limited to being the final destination for generated media. Existing timeline media can become source material for the next generation.

Velvet Avocado Studio includes built-in support for bouncing media from the timeline directly into new generation prompts, including:

- image stills;
- video snippets;
- audio snippets; and
- generation references derived from the current edit.

This makes iterative workflows significantly faster. A creator can assemble a sequence, inspect how a shot works in context, take a still or the closing seconds of that shot, use it as an input to a new prompt, generate the continuation, and return the resulting media to the edit.

The same workflow can support shot continuation, visual matching, alternate takes, audio generation, dialogue replacement, and scene refinement without repeatedly exporting temporary files and rebuilding generation inputs by hand.

The built-in video editor also provides:

- video and audio timeline editing;
- direct access to project media;
- familiar keyboard-shortcut profiles;
- video, cinema, and social resolution presets;
- timeline preview; and
- rendered video export.

Velvet Avocado Studio keeps generation and assembly close together during the part of production where creators are still making and refining creative decisions.

## Local-first storage and local generation

Velvet Avocado Studio is built around local ownership of the production.

Project files, source media, references, generated outputs, prompts, and production metadata live on the user's computer by default using a portable project folder structure. Cloud providers can be used for generation and reasoning, but the project itself does not need to be scattered across provider dashboards, cloud libraries, and download histories.

Velvet Avocado Studio provides:

- local project folders;
- direct access to project media;
- project-aware output placement;
- secure credential storage;
- media browsing and organisation; and
- access to project files outside Velvet Avocado Studio.

Where hardware and model capabilities permit, creators can also run AI workloads locally rather than sending every task to a cloud service.

Current local integrations include ComfyUI, Ollama, and Chatterbox, supporting local media generation and processing, language models, text-to-speech, and voice-cloning workflows.

Local and cloud tools can be used together within the same production. A creator might use a local model for one task, a cloud provider for another, and still keep the resulting assets inside the same project structure.

Velvet Avocado Studio will continue expanding support for local models and runtimes as the local AI ecosystem develops.

The goal is simple: creators should be able to keep ownership of their production files, choose where computation happens, and avoid having the structure of their work dictated by whichever cloud service generated the last asset.

## Free preview and licensing philosophy

Velvet Avocado Studio is currently available as **free preview software**.

We intend to always provide a useful free version of Velvet Avocado Studio.

A future paid version may introduce additional professional features, but our philosophy is that professional creative software should not require an ongoing subscription simply to keep using software you have already purchased.

We take inspiration from products such as DaVinci Resolve and Affinity, which have demonstrated alternative approaches to subscription-only professional creative software.

If paid Velvet Avocado Studio licences are introduced, our principle is straightforward:

**If you buy a software licence, you should retain the right to use that version for as long as it continues to run on your hardware and operating system.**

We do not intend to require an ongoing Velvet Avocado Studio subscription to maintain access to a purchased software version.

Third-party AI providers, APIs, cloud services, and model subscriptions may have their own charges or subscription requirements. Those services are independent of the Velvet Avocado Studio software licence.
