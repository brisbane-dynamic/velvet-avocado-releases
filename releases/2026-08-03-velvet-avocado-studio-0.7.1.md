# Velvet Avocado Studio 0.7.1

Released 3 August 2026

Version 0.7.1 adds a complete voice-and-script workflow to Velvet Avocado, with stronger project chat, local voice tools, and reliability improvements across the desktop app.

## Recording Booth and voice work

- Added the Recording Booth for recording, organising, editing, and reviewing project voice takes.
- Added waveform trimming, level controls, fades, dialogue clean-up, loudness normalisation, take grouping, keeper selection, and recoverable line/take management.
- Added text-to-speech, voice conversion, audio isolation, voice previews, and voice creation where a configured provider supports them.
- Added optional local Chatterbox voice installation in Settings, with on-device text-to-speech and voice conversion for supported Mac and Windows systems.

## Smarter project chat

- Added Studio Functions for visual-style suggestions, still and moving-image prompt improvement, Workflow creation, and screenplay breakdowns.
- Screenplay breakdowns now produce reviewable Characters, Scenes, Locations, Props, and Costumes with source evidence, and can be applied to the project after an explicit preview and confirmation.
- Chat can now create reviewed Workflows from natural-language requests and save the resulting workflow directly to the project.

## Reliability and polish

- Improved macOS prompt dictation and on-device speech handling.
- Improved local-model installation, recovery, cancellation, and storage reporting.
- Improved project opening, recording recovery, provider execution, document previews, and Electron package validation.

## Voice production inside the project

Recording, generated speech, dialogue cleanup, local voice tools, screenplay analysis, and project chat now worked as parts of one production environment. This helped creators keep performances, source lines, generated takes, character information, and reviewed creative decisions connected to the project instead of distributing that context across unrelated recording, generation, and chat applications.
