# Velvet Avocado Studio 0.5.4

Released 22 July 2026

Version 0.5.4 refreshes the Velvet Avocado visual identity and makes desktop releases easier to identify, download, and verify. It is primarily a distribution and presentation update, supporting a clearer path from a published version to the correct installer for each desktop platform.

## Refreshed application icon

- Updated the Velvet Avocado application icon throughout the desktop package.
- Refreshed platform-specific icon sizes so the product identity remains clear in application launchers, Finder, Explorer, task switchers, shortcuts, and installed-app views.
- Kept the same Velvet Avocado name and project-first AI video production experience behind the updated visual presentation.

The icon refresh gives the desktop application a more consistent identity across different operating-system surfaces and display sizes. This is especially useful when creators work with several production applications at once and need to recognise Velvet Avocado Studio quickly among editing, generation, file-management, and post-production tools.

## More consistent desktop downloads

The release process was streamlined around one primary installer format for each supported target: a macOS disk image, a Windows installer, and a Linux AppImage at that point in the product's history. Release metadata also became more structured so the download website could identify a version, its supported platforms, its release status, and the exact files belonging to it.

This work reduced ambiguity around duplicated package formats and inconsistent filenames. The Linux AppImage received a canonical filename, while checksums and release information were organised alongside the installers. Versioned release files remained immutable, while the current release pointer could advance independently when a newer build was ready.

For users, the goal was straightforward: the download page should resolve the intended Velvet Avocado Studio installer, present the correct version, and make future update discovery more dependable without exposing the complexity of the desktop build process.
