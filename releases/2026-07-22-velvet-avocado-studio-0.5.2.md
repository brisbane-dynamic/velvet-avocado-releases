# Velvet Avocado Studio 0.5.2

Released 22 July 2026

Version 0.5.2 adds Atlas Cloud as a bundled media-generation provider, with live model discovery, configurable inputs, model-specific pricing, and clearer final cost reporting.

## Atlas Cloud generation

- Added Atlas Cloud as an active generation provider with a packaged catalogue of more than 300 supported image, video, audio, upscaling, and related media processes.
- Added live model and parameter discovery so the available controls follow Atlas Cloud's current public model schemas.
- Added image, video, and audio reference uploads for compatible models.
- Added direct links from each process to its Atlas Cloud model page.
- Added live configured-request estimates that reflect the selected model, duration, resolution, output count, and account pricing where available.
- Completed token-billed video jobs now report their final cost in US dollars using Atlas Cloud's account-effective rate and actual output usage.
- Improved completed-output retrieval and final media-type handling for jobs that return more than one generated file.

## Smaller fixes

- Corrected the legal company name shown in the application licence and related notices.

## A more connected generation workflow

This release made Atlas Cloud a practical part of a wider AI video production workflow rather than a disconnected model browser. Creators could compare a large catalogue, configure each request with the controls exposed by the selected model, attach project media where supported, and understand likely or final costs without leaving Velvet Avocado Studio. Completed results continued into the same project media system used for reviewing, organising, and reusing production assets.
