# Velvet Avocado Studio 0.1.0

Released 12 July 2026

Version 0.1.0 established Velvet Avocado Studio as a local-first desktop workspace for AI video production, AI-generated media, project assets, prompts, provider connections, conversations, and voice production. It brought the first complete set of project-management and generation workflows together in one application.

## Project-first creative workspace

- Added native project creation, opening, recent-project access, repair, settings, and close flows.
- Created a visible, portable project structure backed by local files and a searchable project database.
- Added resizable and dockable workspace panels, persistent preferences, interface zoom, project navigation, and a unified settings surface.
- Added Characters, Locations, Props, Costumes, Scenes, Imports, Generations, Sound, Trash, Search, Prompt Library, Chat, and Recording Booth destinations.

The project model gave creative work a durable home instead of treating every generated file as an isolated download. Media could be imported, indexed, previewed, searched, assigned to production assets, marked as a favourite, tagged, given workflow roles, moved to Trash, restored, and reviewed through shared grid, list, Gallery, and inspector experiences.

## Multi-provider AI media generation

Version 0.1.0 introduced bundled generation connections for WaveSpeed, OpenRouter, Replicate, fal.ai, ComfyUI, RunwayML, and Higgsfield routes available at the time. Provider catalogues supplied model-specific inputs and controls, while the generation workspace kept the selected model, prompt, attachments, destination, queue state, output, and available cost information connected to the project.

- Added searchable model discovery and favourite models.
- Added provider-owned cost estimates and persisted provider-reported final charges.
- Added durable queued and polling generation jobs with recoverable output retrieval.
- Added project media pickers for image, video, and audio inputs.
- Stored submitted prompt provenance and generation history for later review.

## Prompt, chat, and media workflows

- Added a reusable Prompt Library with bundled and project templates.
- Added persistent project conversations with streaming responses, saved sessions, project attachments, and supported cloud or local chat providers.
- Added background media imports, thumbnails, metadata extraction, folder updates, project search, asset covers, media assignments, and undo for supported moves.
- Added prompt-dock and generation-queue workflows designed to remain available while moving through the project.

## Recording Booth and voice production

The first release also included a Recording Booth for project audio. Creators could record voice takes, organise dialogue lines, review waveforms, play compatible audio, derive edited takes, generate speech through supported providers, perform supported voice conversion or cleanup, and retain take lineage without overwriting the original recording.

Version 0.1.0 set the central direction for Velvet Avocado Studio: organise the entire AI production around the project, keep creative context attached to media, and allow different providers and local tools to participate without replacing the production workspace.
