# Velvet Avocado Studio 0.7.0

Released 2 August 2026

Version 0.7.0 expands the project workspace with an integrated editor, richer media organisation, and more capable document viewing.

## Integrated editor

- Added the embedded FreeCut editor for editing project video in Velvet Avocado.
- The editor now uses your project's frame rate, dimensions, and other video defaults when starting a new edit.
- Added export to OpenTimelineIO and Final Cut Pro XML, preserving source timecode where it is available.
- Added configurable editor keyboard profiles and improved playback, theme, and export reliability.

## Media organisation

- Added a hierarchical generation media browser to make project outputs easier to find and manage.
- Imported media becomes available while analysis and thumbnails continue in the background.
- Improved media selection, role filtering, picker navigation, and thumbnail updates.
- Added generation cost and usage reporting based on completed work.

## Document viewing

- Added built-in previews for project documents, including polished PDF and Word document presentation.
- Improved document icon clarity, page scrolling, and reliability when loading large previews.

## Reliability

- Improved project permissions and editor workspace recovery.
- Refined update feedback and project-close behaviour.

## From generated media to an editable production

The integrated editor connected asset management and AI-generated media with the next stage of production. Creators could move from organised project files into a rough edit, use project defaults when creating a timeline, and prepare interchange files for professional post-production tools. Combined with the hierarchical generation browser and improved document previews, this release made Velvet Avocado Studio a more complete home for planning, generating, reviewing, and assembling AI video projects.
