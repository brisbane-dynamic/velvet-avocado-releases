# Velvet Avocado Studio 0.5.3

Released 22 July 2026

Version 0.5.3 expands Atlas Cloud into a complete media and chat provider and makes it easier to connect during first-time setup.

## Atlas Cloud chat

- Added Atlas Cloud as a bundled chat provider using the same securely saved API key as Atlas Cloud media generation.
- Added live discovery of Atlas Cloud's available language and vision models, including context limits and direct links to individual model pages.
- Added live input, output, cached-input, and long-context pricing displayed in US dollars per million tokens for straightforward model comparison.
- Added streaming and standard chat responses, image attachments for compatible vision models, and returned token-usage reporting.
- Kept media and chat enablement independent so either capability can be used on its own while sharing one Atlas Cloud connection.

## Provider setup

- Added Atlas Cloud to the first-use provider setup assistant for both media and chat.
- Reordered the recommended provider list to surface ComfyUI first, followed by Atlas Cloud, WaveSpeed, Higgsfield, and OpenRouter, with Ollama available for local chat.
- Added an Atlas Cloud setup guide covering credentials, catalogue testing, pricing, supported inputs, and common connection issues.

## One connection for media and creative planning

Atlas Cloud could now support both generation and project conversation while keeping those capabilities independently selectable. This gave creators a consistent connection for discovering visual models, working with language and vision models, comparing token pricing, and streaming responses inside the same local-first production workspace. The expanded onboarding and setup guidance also made it easier to understand where Atlas Cloud fitted alongside ComfyUI, WaveSpeed, Higgsfield, OpenRouter, and Ollama.
