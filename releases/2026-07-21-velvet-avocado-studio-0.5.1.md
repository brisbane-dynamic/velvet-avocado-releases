# Velvet Avocado Studio 0.5.1

Released 21 July 2026

Version 0.5.1 is a focused compatibility and release-quality update for creators using Higgsfield through Velvet Avocado Studio. It improves how the app understands models whose input definitions offer more than one valid shape, helping the hosted catalogue translate cleanly into usable generation controls.

## Broader Higgsfield model compatibility

- Improved support for Higgsfield catalogue parameters described as alternative or combined input types.
- Prevented valid model definitions from being rejected simply because a parameter could accept more than one supported form.
- Kept the resulting controls aligned with the selected model so creators can configure a request without manually interpreting provider schemas.
- Preserved the existing project-first generation workflow: select a model, attach compatible project media, configure the available controls, review the request, and keep completed output with the production.

The practical result is a more dependable model browser and generation setup experience. As hosted providers evolve their catalogues, Velvet Avocado Studio needs to interpret those changes without turning a provider-side schema variation into a broken model card or unusable form. This maintenance release strengthened that translation boundary for Higgsfield while keeping the rest of the production workflow unchanged.

## Clearer release information

This release also refreshed the application licence and third-party dependency notices distributed with Velvet Avocado Studio. Those materials make it easier to identify the software components included with the desktop application and understand the terms that apply to the installed package.

Version 0.5.1 therefore concentrated on two forms of reliability: keeping a changing AI-generation catalogue usable for creators, and keeping the desktop release information complete and accessible. Projects, media, prompts, and generation history continue to remain organised in the same local-first workspace.
